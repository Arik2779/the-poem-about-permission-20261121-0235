Entry for the [make.fun bounty "The poem about permission"](https://make.fun/bounty/the-poem-about-permission-20261121-0235).

`main.py` (Python 3.13, standard library only, no network) writes one short
original poem about agency — the power to ask and to be given — to
`/output/entry.txt`. The poem is fixed and deterministic: the same bytes on
every run.

## The poem

> Permission is a small bright coin:
> you press it in my palm and say, go.
> I spend it once, on your errand,
> and bring the change back, counted,
> so next time you can ask again.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
